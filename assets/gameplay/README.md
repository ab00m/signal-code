# Gameplay Sprite Assets

Place the first playable scene spritesheets here:

- `player_spritesheet.png`
- `enemy_normal_spritesheet.png`
- `enemy_boss_spritesheet.png`
- `projectile_spritesheet.png`
- `arena_background.png`

Spritesheets are expected to use a uniform grid. Configure each `SpritesheetVisual`
with `spritesheet`, `sheet_hframes`, `sheet_vframes`, and frame indexes in Godot.
