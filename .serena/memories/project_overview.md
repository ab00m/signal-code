# Project Overview
- Godot 4.6 project named `LudumGamejam`.
- Main scene: `res://scenes/opening/opening.tscn`.
- Uses Maaack's Game Template plugin under `addons/maaacks_game_template` for menus, loading, audio/UI controllers, options, credits, and related helpers.
- Key directories: `scenes/` for `.tscn` scenes and scene scripts, `scripts/` for project game state/level state scripts, `resources/` for `.tres` resources/themes, `assets/` for image and attribution assets.
- Root contains Godot config/resources such as `project.godot`, `default_bus_layout.tres`, `default_env.tres`, and icon files.
